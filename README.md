## What I'm working on

### [GymFlow](https://github.com/PietraAC/GymFlow)

A microservices portfolio project where gyms manage branches and equipment inventory, while students create workout plans restricted to exercises available at their selected branch.

The current version uses Java 21, Spring Boot, Angular, PostgreSQL, Flyway, Docker, and Keycloak. Its roadmap adds a reviewable AI assistant and a real RabbitMQ event flow without bypassing domain validation or user confirmation.
